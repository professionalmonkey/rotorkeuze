# Rotorkeuze

Rotorselectie voor silicagel-droogrotoren: series doorrekenen met de HyTek-calculator of met een eigen
rekenmodel, een droger ontwerpen en dimensioneren, en de heaterbox doorrekenen.

## Installeren

1. Download **[RotorkeuzeSetup.exe](../../releases/latest/download/RotorkeuzeSetup.exe)** (nieuwste versie).
2. Start het bestand. Windows kan waarschuwen omdat de setup niet ondertekend is: kies *Meer info* > *Toch uitvoeren*.
3. De setup installeert Python en de onderdelen zelf (ca. 2-5 minuten) en maakt een snelkoppeling op het bureaublad.

## Bijwerken

Rotorkeuze werkt zichzelf bij: bij het starten verschijnt een melding als er een nieuwe versie is.
Zelf controleren kan via *Help > Controleren op updates*. Alle versies staan onder [Releases](../../releases).

Deze repository bevat alleen de installatie- en updatebestanden; de broncode is niet openbaar.
